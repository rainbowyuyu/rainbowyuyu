### About / 我在做什么

我是浙江大学的学生 **俞天翼**，也以 **rainbow鱼 / rainbowyuyu** 分享作品。

我关心 AI 如何走进真实的物理与工程问题：从风场预测、物理仿真，到能建模、计算、检查结果的工程智能体。另一条长期主线，是把公式、算法和科学机制变成直观的交互与动画。

目前主要投入 **PhysCast、OmniForge 和 Wiscomper**：探索物理世界的预测，让工程工具协同工作，也让复杂知识更容易理解。
