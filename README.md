## 关于我

我是 **rainbow鱼**，浙江大学博士。我在 AI、物理仿真与工程之间做研究、写工具，也用交互可视化和动画讲清复杂的知识。

目前主要投入 **PhysCast、OmniForge 和 Wiscomper**：研究物理世界的预测，让工程工具协同工作，也让数学推理更容易理解。
